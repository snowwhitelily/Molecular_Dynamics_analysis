Project Dependencies

numpy
Core numerical computation library used for matrix operations and PCA calculations.

pandas
Used for tabular data handling and occupancy analysis.

matplotlib
Used for plotting PCA projections and clustering results.

scikit-learn
Provides PCA implementation and DBSCAN clustering.

hdbscan
Primary clustering algorithm used for identifying conformational states.

scipy
Scientific computing utilities used for numerical routines.

jupyter
Environment used to run the notebook.
